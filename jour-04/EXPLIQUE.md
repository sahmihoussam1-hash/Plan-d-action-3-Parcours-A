# jour 4 : map et reduce 

- map retourne un tableau de meme taille : chaque element est transforme(ici le titre en majuscules).
- reduce retourne une seule valeur : l'accumulateur part de 0 et on lui ajoute un prix a chaque tour.
- filter puis map :filter garde les articles a moins de 200 DH, map extrait leur titre.
